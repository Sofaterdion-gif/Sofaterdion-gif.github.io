## Windows 試玩版狀態

**新版 Godot Windows 試玩版目前尚未發布。** 目前沒有可供核對的新版 EXE 或 GitHub Release，官網下載入口暫停。

原本位於儲存庫根目錄的 `OpenBell-Playtest.exe` 是舊版 **SFML** 開發包，不是目前的 Godot 遊戲；它已移至 `archive/legacy-sfml/`，不應當成最新版下載或用來評估新版效能。舊檔未附 Authenticode 簽章。

待新版通過實機與完整性驗證後，再發布 Windows x64 套件；建議一併提供檔案大小、SHA-256、所需資料檔清單與簽章狀態。

# Open Bell Playtest

![Open Bell cover](open-bell-cover.svg)

## 目前可玩試玩版

這是 Open Bell 的 Windows / PC 開發中試玩版。可以體驗交易、行情回放與目前已完成的核心玩法，但內容、平衡與介面仍會持續調整，**不是最終版本**。

**[下載 OpenBell-Playtest.exe](https://github.com/Sofaterdion-gif/Sofaterdion-gif.github.io/raw/refs/heads/main/OpenBell-Playtest.exe)**

- 平台：Windows 64-bit
- 狀態：開發中試玩版
- 行動版：測試階段，尚未作為正式下載
- 製作地：Taiwan (Republic of China)

下載後直接雙擊 `.exe` 即可啟動。若 Windows 顯示 SmartScreen 提示，請確認檔案來源是本專案 GitHub Pages repository。
